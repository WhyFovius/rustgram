# Ревью проекта — 3 ноября 2026

Проверены Rust workspace, JNI, Compose-экраны, Android Manifest и цепочка сборки. Это обзор исходников и автоматические проверки; вход в реальный аккаунт и визуальная проверка на устройстве не выполнялись.

## Исправлено

- ID диалогов переведены с `i32` на `i64` во всех моделях, событиях, командах и JSON-хранилище. Убраны преобразования, обрезавшие ID групп/каналов. Старые JSON с 32-битными ID продолжают читаться; уже обрезанные значения восстановить автоматически нельзя.
- Повторный вызов JNI `start` сохраняет существующую сессию вместо создания ещё одного TDLib worker. Очередь событий теперь обрабатывается в локальное хранилище; один poll ограничен 256 событиями.
- Ошибки инициализации, телефона, кода и пароля передаются из TDLib через JNI и отображаются в форме. Значение поля очищается при смене этапа, а после ошибочного ввода сохраняется для исправления.
- Пароль скрыт визуальной трансформацией. JNI корректно преобразует строки с supplementary Unicode-символами вместо замены всего значения пустой строкой.
- Отметка входящих прочитанными больше не ставит исходящим ложную квитанцию. `interaction_info` также больше не трактуется как квитанция прочтения. Серверный `view_messages` получает ID последнего сообщения вместо пустого массива.
- Устранены перезапись настоящих диалогов синтетическими записями из контактов и переполнение счётчика непрочитанных.
- Gradle берёт `libtdjson.so` из `out_dir`, сообщённого текущей Cargo-сборкой, и использует `--locked`, вместо выбора библиотеки от старой сборки по времени изменения.
- Декоративные слои `GlassSurface` используют `matchParentSize`, поэтому не растягивают панель до размера экрана. Вызовы RuntimeShader защищены проверкой API 33.
- Форма входа прокручивается при открытой клавиатуре; включён `adjustResize`. Системная кнопка «Назад» закрывает открытую переписку. Фильтры допускают горизонтальную прокрутку, длинное название чата сокращается многоточием.
- Для Android 12+ явно исключены данные приложения из облачного backup и переноса между устройствами. Камера и микрофон объявлены необязательными; добавлена monochrome-иконка.

## Что остаётся

1. **Функциональность:** Compose показывает демонстрационные чаты и сообщения; кнопки отправки, поиска, фильтров и настроек в основном заглушки. Регистрация, QR/email-подтверждение и другие невыведенные состояния авторизации попадают в экран подключения.
2. **Жизненный цикл TDLib:** несколько независимых транспортов конкурируют за глобальный `receive()`. `stop()` синхронно ждёт worker; зависший сетевой запрос может задержать остановку. Нет полноценного graceful close/restart и обработки падения worker. Защита JNI от повторного старта устраняет основной путь создания дубликатов в приложении, но не заменяет диспетчер TDLib.
3. **Синхронизация данных:** часть обновлений возвращает только `DialogChanged`, а store не запрашивает свежий Chat. У Message нет ID для дедупликации, редактирования, удаления и read receipts. Загрузка истории заменяет список вместо объединения страниц. Отображение времени использует UTC; каналы пока классифицируются как группы.
4. **Хранение:** JSON persistence — незашифрованный прототип. TDLib получает пустой database encryption key. Нужна отдельная политика хранения с Android Keystore и миграцией существующей базы; простая смена ключа при старте может сделать её недоступной. Очереди и история в памяти не имеют общего лимита.
5. **Поставка:** release подписан debug-ключом. API application credentials встроены в код и упомянуты в старом PROJECT_STATUS.md; их конфигурацию нужно отделить от исходников перед публичным распространением. NDK-пути привязаны к машине, Android ABI пока только arm64.
6. **UI:** зафиксирована портретная ориентация, некоторые элементы имеют фиксированную высоту и требуют проверки с увеличенным шрифтом/TalkBack. Полный вход, API 26/31/33, клавиатура и отрисовка стекла на устройстве не проверены.

## Проверки

- `cargo test --workspace --locked` — регрессионные тесты ID, JSON, статусов прочтения и ошибок.
- `cargo clippy --workspace --all-targets --locked -- -D warnings`.
- `cargo clippy -p rustgram --target aarch64-linux-android --release --locked -- -D warnings` — отдельно проверяет JNI-код, исключённый из desktop-сборки.
- `gradlew :app:assembleDebug :app:lintDebug` — сборка и Android Lint. Предупреждения об обновлениях зависимостей/target SDK, портретной ориентации и каталоге ресурсов v26 оставлены без массового обновления стека.
- `cargo fmt --all -- --check` обнаруживает существующие расхождения форматирования в нескольких Rust-файлах. Глобальное переформатирование не выполнялось, чтобы не смешивать исправления с большим косметическим diff.
